# Chronexus Server brand assets

These two presentation assets are byte-for-byte copies from the original
[Chronexus brand directory](https://github.com/Acelith/Chronexus/blob/main/assets/brand).
The original project records the herald illustrations as user-selected assets
created without campaign data. No artwork was generated or modified for this README.

| File | Use |
| --- | --- |
| `chronexus-wordmark.webp` | README header with accessible Chronexus text |
| `chronexus-icon.webp` | README footer |

The original source artwork remains in the Chronexus repository. Keep these
copies unchanged; obtain future variants from the original project's brand sources.
