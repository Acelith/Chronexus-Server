# Chronexus-Server

Planned self-hosted server for Chronexus: optional campaign sharing, selective
synchronization, user management and cross-device access. The desktop remains
local-first, and content stays private until explicitly shared.

The server is not implemented yet. See the [roadmap](ROADMAP.md) for milestones
and acceptance criteria, and [implementation status](docs/STATUS.md) for the
current checkpoint and decisions required before coding.
