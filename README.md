# Chronexus-Server

Planned self-hosted server for Chronexus: continuous saving to local and private
server copies for opted-in campaigns, selective sharing and cross-device access.
The roadmap also includes a choice of local or self-hosted server AI, simple Docker
Compose deployment with configurable ports, and a web management interface. The
desktop remains local-first; synchronization does not share data with other players.

The server is not implemented yet. See the [roadmap](ROADMAP.md) for milestones
and acceptance criteria, and [implementation status](docs/STATUS.md) for the
current checkpoint and decisions required before coding.
