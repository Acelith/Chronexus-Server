# Chronexus Server 0.2.0 — Chronexus Table

The first release with the virtual tabletop. A GM creates a table, invites players
and spectators, and runs the game from the server web interface; players join from
the browser or from Chronexus 0.13.0 on the desktop.

**New**
- **Tables and seats (M42–M43):** GM accounts (`invite --gm`), invitation-only seats,
  a live channel with presence and reconnection, explicit per-item GM journal access.
- **Maps, grid and tokens (M44):** scenes with PNG/JPEG/WebP or Universal VTT maps,
  square and hex grids, calibration, difficult terrain, tokens with movement cost,
  rulers and area templates. Every distance shows feet and metres.
- **Combat (M45):** initiative (manual or d20), turn order, rounds, delay, conditions
  with durations, owner-only HP/AC and a filtered combat log.
- **Fog and vision (M46):** manual fog, walls, doors, lights, per-token vision and
  darkvision; hidden information is filtered on the server.
- **Monsters, encounters and images (M47):** editable SRD 2014/custom monsters with
  source attribution, saved encounters, an image library and Wikimedia Commons import.
- **Table workspace:** tool palette, zoom/pan/fit map, full screen and a tabbed
  sidebar (Chat, Tokens, Combat, Measure, Scenes, Fog, Library, Players).
- **Chat dice and pings:** `/r 2d20kh1+5`, `/gr` secret rolls and `/w gm` whispers,
  rolled and scoped by the server; transient map pings on the active scene.

**Fixed**
- The table join form showed `{role}` and `{date}` placeholders.

**Upgrade:** automatic schema migration 006 → 016, additive only. Back up first
(`chronexus-server backup FILE`). Existing campaigns, accounts and sessions are kept.

**Works with** Chronexus 0.9.0 and later for sharing; tables need Chronexus 0.13.0.

**Verified on Windows x64:** full Rust test suite, Clippy with warnings denied,
rustfmt, contract drift check, 33 web DOM tests, a browser session on a synthetic
loopback server and the desktop three-player live scenario. Container images are
built by GitHub Actions for linux/amd64 and linux/arm64. Native macOS/Linux play,
production TLS and LAN latency measurements remain open.
